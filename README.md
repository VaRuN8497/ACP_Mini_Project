# ACP_Mini_Project
# 🎨 2D Graphics Editor (C Language)

This project is a simple 2D graphics editor built using C.  
It works completely in the terminal and uses characters like * and _ to draw shapes.

---

## 📌 Features

- Draw Line
- Draw Rectangle
- Draw Circle
- Draw Triangle
- Add multiple shapes
- Delete shapes using ID
- Modify existing shapes
- Display canvas in terminal
- Demo scene available

---

## 🛠️ Technologies Used

- C Programming
- 2D Arrays
- Structures
- Terminal Output

---

## ▶️ How to Run

1. Compile the program:
   gcc ACP_mini_project.c -o editor -lm


2. Run the program:
   ./editor

---

## 🧠 Working

- A 2D array is used as a canvas.
- Shapes are drawn by updating positions in the array.
- Structures are used to store multiple objects.
- Each object has an ID for easy deletion and modification.
- The canvas redraws after every change.
